# Ticket T3.1: Parametric Camera Sensor Model

- **Milestone:** M3 (Imperfect observation and sensing–control gap)
- **Status:** Ready
- **Decision References:** `D-005` (sensor seam), `D-017` (seed discipline), `D-021` (camera model), `D-033` (lane and stationary fields).

## 1. Goal

Implement a parametric camera sensor model (`CameraSensor`) in `traffic_lab/sensing/camera.py`
that satisfies the `SensorModel` protocol. The model simulates field of view limits, distance-dependent
detection dropout, measurement noise on position and speed, and transmission latency.

## 2. Specification

### 2.1 Configuration (`CameraConfig`)
```python
@dataclass(frozen=True, slots=True)
class CameraConfig:
    sensor_id: SensorId
    position_xy: tuple[float, float]
    heading_rad: float
    fov_rad: float
    range_m: float
    p_det_0: float = 0.95
    pos_noise_std: float = 0.5
    speed_noise_std: float = 0.3
    latency_s: float = 0.0
    seed: int = 42
```

### 2.2 Operational Mechanics
1. **Geometric Visibility:**
   - Compute relative vector $\mathbf{v} = (x_v - x_c, y_v - y_c)$ and distance $d = \|\mathbf{v}\|_2$.
   - Vehicle is out of view if $d > \text{range\_m}$.
   - Compute bearing angle $\phi = \operatorname{atan2}(v_y, v_x)$ and angular difference $|\phi - \theta_c| \pmod{2\pi}$.
   - Vehicle is out of view if angular difference exceeds $\text{fov\_rad} / 2$.
2. **Stochastic Detection Probability:**
   - If geometrically visible, detection probability is:
     $$P_{\text{det}}(d) = p\_det\_0 \cdot \max\left(0, 1 - \frac{d}{2 \cdot \text{range\_m}}\right)$$
   - Sample uniform random variable $u \sim \mathcal{U}(0, 1)$ using sensor RNG stream. If $u > P_{\text{det}}(d)$, vehicle is dropped (false negative).
3. **Noisy Measurements:**
   - Sample coordinate noise $\epsilon_x, \epsilon_y \sim \mathcal{N}(0, \sigma_{\text{pos}}^2)$.
   - Sample speed noise $\epsilon_v \sim \mathcal{N}(0, \sigma_{\text{speed}}^2)$.
   - Set `position_xy = (x_v + \epsilon_x, y_v + \epsilon_y)`.
   - Set `speed_mps = \max(0.0, v_v + \epsilon_v)`.
   - Set `position_cov = (\sigma_{\text{pos}}^2, \sigma_{\text{pos}}^2, 0.0)`.
   - Set `speed_std = \sigma_{\text{speed}}`.
4. **Latency:**
   - Set `received_at_s = now_s + latency_s`.

## 3. Acceptance Criteria

| Criterion | Verification Method |
| --- | --- |
| Protocol compliance | `isinstance(sensor, SensorModel)` passes |
| Strict FOV masking | Vehicles outside angle or range produce 0 detections |
| Distance-dependent dropout | Measured empirical detection rate matches $P_{\text{det}}(d) \pm 0.03$ over 1,000 samples |
| Noise distribution | Empirical standard deviation of detected positions matches configured $\sigma$ |
| Seed repeatability | Identical seed produces identical sequence of drops and noise |
| Pure import boundary | `traffic_lab/sensing/camera.py` does not import `traffic_lab/control/` |

## 4. Non-Goals

- No pixel generation, bounding box regression, or camera calibration matrices.
- No dynamic weather or lighting simulation.
