# Ticket T3.3: Type Boundary and Truth Leakage Enforcement

- **Milestone:** M3 (Imperfect observation and sensing–control gap)
- **Status:** Ready
- **Decision References:** `D-005` (separation of truth and estimate), `D-033` (signal passthrough), `AGENTS.md` §2 Invariant 1.

## 1. Goal

Enforce the structural boundary between `TrueState`, `Observation`, and `EstimatedState`.
Add executable test suites that fail if any controller or estimator imports `TrueState`, or if
any sensed experiment arm passes `TrueState` directly to a decision agent.

## 2. Specification

1. **AST Import Inspection:**
   - Extend `tests/control/test_control_import_boundary.py` to cover `traffic_lab/estimation/`.
   - Ensure neither `traffic_lab/control/` nor `traffic_lab/estimation/` imports `TrueState` or `traffic_lab.domain.state.TrueState`.
2. **Negative Contract Testing:**
   - Add unit tests verifying that passing `TrueState` to `controller.decide()` raises a type or runtime error.
   - Verify that `SensorModel` is the only component in the simulation loop converting `TrueState` to `Observation`.

## 3. Acceptance Criteria

| Criterion | Verification Method |
| --- | --- |
| Zero Truth Leaks | `pytest tests/control/test_control_import_boundary.py` passes |
| Type Guard Tests | Unit tests verify `controller.decide` only accepts `EstimatedState` |
| Sensed Arm Isolation | Experiment runner enforces `sensor.observe()` -> `estimator.update()` -> `controller.decide()` |
