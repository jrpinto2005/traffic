# Ticket T3.4: 2D Visual Divergence Overlay in Replay Renderer

- **Milestone:** M3 (Imperfect observation and sensing–control gap)
- **Status:** Ready
- **Decision References:** `D-009` (renderer decoupling), `D-030` (trace format channels), `03_ROADMAP.md` M3 exit criteria.

## 1. Goal

Enable `ReplayRenderer` to visualize ground truth and imperfect observations simultaneously.
When observation channels are present in trace frames, render visual divergence between true
vehicle states and noisy/dropped camera detections.

## 2. Specification

1. **Trace Channel Population:**
   - Record `observations` and `estimates` in `StepFrame` during camera-sensed runs (`D-030`).
2. **Visual Overlays:**
   - **True Vehicles:** Solid markers colored by actual velocity.
   - **Observed Detections:** Hollow rings/circles centered at noisy observed $(x_d, y_d)$ coordinates.
   - **Dropped Vehicles:** True vehicles without an overlay ring visibly indicate sensor false negatives.
   - **HUD Divergence Metric:** Display real-time comparison:
     `QUEUE DISCREPANCY: True N vs Estimated M (Error: +/- K)`

## 3. Acceptance Criteria

| Criterion | Verification Method |
| --- | --- |
| Visual Divergence Display | Rendered frame visibly shows displaced detection rings and unringed dropped vehicles |
| Dual HUD Telemetry | HUD displays true in-network count alongside estimated lane queues |
| Offline Execution | Divergence renders without SUMO or live sensors |
