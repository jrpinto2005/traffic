# Ticket T3.2: Counting-with-Decay State Estimator

- **Milestone:** M3 (Imperfect observation and sensing–control gap)
- **Status:** Ready
- **Decision References:** `D-005` (estimator seam), `D-021` (counting with decay), `D-033` (signal passthrough), `D-036` (detection zone).

## 1. Goal

Implement `CountingWithDecayEstimator` in `traffic_lab/estimation/decay.py` satisfying the
`Estimator` protocol. The estimator maintains per-lane tracking and applies exponential decay
to unobserved lanes, enabling controllers to operate under partial sensor coverage and camera dropouts.

## 2. Specification

### 2.1 Configuration
```python
@dataclass(frozen=True, slots=True)
class DecayEstimatorConfig:
    half_life_s: float = 15.0  # Time for unobserved count to halve
    zone_s: float = 2.0  # Stop-line detection zone duration
    default_queue_std: float = 1.0  # Base uncertainty when decaying
```

### 2.2 Operational Mechanics
1. **Per-Lane Tracking Memory:**
   - Store historical state per lane: $\hat{N}_l, \hat{Q}_l, \hat{Z}_l$ (vehicle, queue, zone counts) and $t_{\text{last}, l}$.
2. **Observed Lanes Update:**
   - For lanes in `obs.observed_lanes`:
     - Count detections directly: $N_{\text{obs}}, Q_{\text{obs}}, Z_{\text{obs}}$.
     - Update $\hat{N}_l = N_{\text{obs}}$, $\hat{Q}_l = Q_{\text{obs}}$, $\hat{Z}_l = Z_{\text{obs}}$.
     - Set $t_{\text{last}, l} = \text{obs.received\_at\_s}$.
     - Set uncertainty `queue_count_std = 0.0`.
3. **Unobserved Lanes Decay:**
   - For lanes outside `obs.observed_lanes`:
     - Calculate $\Delta t = \max(0.0, \text{now\_s} - t_{\text{last}, l})$.
     - Compute decay factor: $\lambda = \exp(-\Delta t \cdot \frac{\ln 2}{\text{half\_life\_s}})$.
     - Decayed estimates: $\hat{N}_l(t) = \lambda \cdot \hat{N}_l(t_0)$, $\hat{Q}_l(t) = \lambda \cdot \hat{Q}_l(t_0)$, $\hat{Z}_l(t) = \lambda \cdot \hat{Z}_l(t_0)$.
     - Uncertainty grows with time: $\sigma_Q = \text{default\_queue\_std} \cdot (1.0 - \lambda)$.
4. **EstimatedState Output:**
   - Return `EstimatedState(time_s=now_s, lanes=..., signals=signals)`.

## 3. Acceptance Criteria

| Criterion | Verification Method |
| --- | --- |
| Protocol compliance | `isinstance(estimator, Estimator)` passes |
| Partial coverage tolerance | Does not raise when `obs.observed_lanes` covers only a subset of network lanes |
| Exponential decay rate | After `half_life_s` without observation, count equals $0.5 \times \text{initial count} \pm 10^{-4}$ |
| Non-negative invariant | Queue and vehicle estimates remain $\ge 0.0$ at all times |
| Signal passthrough | `EstimatedState.signals` matches input `signals` exactly |
| Pure import boundary | `traffic_lab/estimation/decay.py` does not import `TrueState` |

## 4. Non-Goals

- No Kalman filter, particle filter, or neural network estimator.
- No dynamic origin-destination route inference.
