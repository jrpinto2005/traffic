# T2.3 — 2D Replay Renderer Engine and Overlays

**Archetype:** Builder · **Depends on:** T2.1 · **Implements:** `D-009`, `D-030`

## Context
Per `03_ROADMAP.md` M2 and `01_CRITICAL_REVIEW.md` O-5, replay visualization must run
completely decoupled from SUMO. The renderer consumes trace files produced by `TraceWriter`
and renders 2D animation frames with research overlays:
- Road geometry and lane boundaries.
- Vehicles with velocity-colored markers and IDs.
- Active traffic signal states per movement/approach.
- Halting queue visualizations and per-lane jam lengths.
- Live telemetry HUD (clock, arrived vehicles, in-network count, mean delay).
- Play, pause, step, and scrub controls.

## Contract

```python
@dataclass(frozen=True)
class RenderConfig:
    width_px: int = 800
    height_px: int = 800
    show_queues: bool = True
    show_signals: bool = True
    show_metrics: bool = True
    show_vehicle_ids: bool = False
    fps: int = 10

class ReplayRenderer:
    def __init__(self, trace_reader: TraceReader, config: RenderConfig | None = None) -> None: ...
    def render_frame(self, frame: StepFrame) -> PIL.Image.Image: ...
    def export_gif(self, out_path: Path, start_step: int = 0, end_step: int | None = None, fps: int = 10) -> Path: ...
```

## Scope
1. Implement `traffic_lab/viz/renderer.py`:
   - Standalone 2D rendering pipeline using matplotlib/Pillow.
   - Drawing static geometry: center junction, approach roads, stop lines.
   - Drawing dynamic entities: vehicle positions, headings, speed colors.
   - Research overlays: signal heads (green/yellow/red circles), queue indicators, metrics HUD.
   - Single-frame rasterizer returning `PIL.Image.Image` or numpy RGB array.
   - Multi-frame video/GIF exporter (`export_gif`).
2. Operates 100% offline without SUMO (`traci`/`libsumo` never imported).
3. Provide interactive replay script / CLI utility (`scripts/replay_trace.py`).

## Non-goals
1. Do NOT build a 3D or WebGL renderer (roadmap non-goal).
2. Do NOT permit real-time simulation intervention (this is replay only).
3. Do NOT import SUMO.
