# T2.2 — Trace Reader and Integrity Validator

**Archetype:** Builder · **Depends on:** T2.1 · **Implements:** `D-030`

## Context
Replay visualizers must parse trace files without depending on SUMO or any simulation
libraries. The reader loads header metadata and step frames line by line.

## Contract

```python
class TraceReader:
    def __init__(self, trace_path: Path) -> None: ...
    def iter_frames(self) -> Iterator[StepFrame]: ...
    def read_all_frames(self) -> list[StepFrame]: ...
    def close(self) -> None: ...
```

## Scope
1. Support both uncompressed `.jsonl` and gzip-compressed `.jsonl.gz`.
2. Header validation (`trace_version: "1.0"` required; mismatch raises `ValueError`).
3. Memory efficiency: `iter_frames()` yields frames on-demand.
4. Clean context manager support (`__enter__`, `__exit__`).

## Acceptance Criteria
- [x] Correctly reads both raw and gzipped trace files.
- [x] Raises `ValueError` if trace version does not match `1.0`.
- [x] Yields valid `StepFrame` objects with vehicle lists, signals, queues, and metrics.
- [x] Operates in pure Python without importing SUMO.
