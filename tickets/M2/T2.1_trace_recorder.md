# T2.1 — Trace Schema and Streaming Recorder

**Archetype:** Builder · **Depends on:** M1 · **Implements:** `D-030`

## Context
Per `D-030`, M2 decouples visualization from SUMO. The simulation records per-step vehicle
positions, signal phase states, queue lengths, and performance counters. It reserves empty
channels for future observations, estimates, and controller actions (`M3+`).

## Contract

```python
@dataclass(frozen=True)
class TraceHeader:
    trace_version: str
    run_id: str
    step_length_s: float
    geometry: dict[str, Any]
    measurement_window: dict[str, float]

class TraceWriter:
    def __init__(self, out_path: Path, header: TraceHeader, compress: bool = False) -> None: ...
    def write_step(
        self,
        step: int,
        time_s: float,
        vehicles: list[dict[str, Any]],
        signals: dict[str, Any],
        queues: dict[str, Any],
        metrics: dict[str, Any],
        observations: dict[str, Any] | None = None,
        estimates: dict[str, Any] | None = None,
        decisions: dict[str, Any] | None = None,
    ) -> None: ...
    def close(self) -> None: ...
```

## Scope
1. Define trace data schema with `trace_version: "1.0"`.
2. Streaming `TraceWriter` supporting raw `.jsonl` and gzip-compressed `.jsonl.gz`.
3. Extract static network geometry from `Network` object on initialization.
4. Integrate `record_trace: bool = False` into `RunConfig` and `traffic_lab/experiments/runner.py`.
5. Ensure 0% overhead and 0 file writes when `record_trace` is False.

## Non-goals
1. Do NOT implement the replay GUI or frame painter (T2.3).
2. Do NOT populate observations or estimates (M3).
3. Do NOT use `pyarrow` (`D-004`).

## Acceptance Criteria
- [x] A simulation run with `record_trace=True` writes a valid line-by-line trace file.
- [x] Line 0 contains static geometry and metadata header; subsequent lines contain step frames.
- [x] Reserved channels (`observations`, `estimates`, `decisions`) are present in each step frame as null.
- [x] Compressed `.jsonl.gz` produces identical decompressed content to `.jsonl`.
- [x] A run with `record_trace=False` generates no trace file and introduces no measurement overhead.
