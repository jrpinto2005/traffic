## Summary
Every controller — from Webster fixed-time to RL at M7 — acts through one interface, so
controllers differ in *how they choose* rather than in *what they are allowed to choose*. The
constraint layer enforces min/max green, yellow, all-red, and phase legality against the
conflict matrix, so no controller has to and no controller can bypass it.

Two tiers, and the separation is a safety property rather than an efficiency one: the
**constraint layer runs every simulation step** (timers, transitions — negligible cost), the
**policy runs every Δt**. If the layer only ran at decision points, a yellow interval could
overrun by up to Δt.

## Addition since the worked example was written

`D-020` now also requires a legal-action mask on the constraint layer:

```python
def allowed_phases(self, intersection_id: IntersectionId) -> frozenset[PhaseId]
```

It generalises `actionable()` from "can I act" to "which actions are legal", it leaks nothing
(derivable from the controller's own signal state plus the static conflict matrix), and adding
it now avoids changing the `Controller` protocol at M7. Adopted from PyTSC via T0.1. The
per-outcome counters stay: a masked controller that still requests an illegal phase is a bug
worth seeing.

## You own one clause of invariant 9

`05_DOMAIN_MODEL.md` §8 invariant 9 requires `decision_interval_s <= min_green_s`. `SignalTiming`
(§2.7) has no `decision_interval_s` field — it is controller-layer configuration, not network
structure — so T1.2 could not validate it and correctly left it here. Reject it at config load
with a clear error, as your acceptance criteria already require.

## Known gap, already registered
`D-020` does not say what happens when max green expires **while a phase transition is in
progress**. The provisional answer recorded in the register is that the override **waits**,
and the resulting overshoot (up to `yellow_s + all_red_s`) is recorded in the manifest so it
is visible rather than silent.

Confirm this at implementation. If waiting turns out to be unworkable, **escalate** — this is
item 2 of the ticket's `Escalate if` list and it is a decision, not an implementation detail.
