# T1.2 — Domain types and invariant validators

**Archetype:** Builder · **Depends on:** T0.0
**Implements:** `D-003`, `D-010`, `D-011`, `D-012`, `D-020`, `D-023`, `D-025`

## Context
The project's vocabulary. Everything downstream imports these and nothing else imports
backwards. Pure data plus validation — **no behaviour, no I/O, no backend knowledge.**

## Contract
Implement exactly the types in `05_DOMAIN_MODEL.md` §§2–5, verbatim. That document **is** the
contract; this ticket does not reinterpret it.

Sections in scope: 2.1 `Edge`, 2.2 `Lane`, 2.3 `LaneConnection`, 2.4 `Junction` and
`SignalizedIntersection`, 2.5 `ConflictMatrix`, 2.6 `Movement` (a derived view — a function,
**not** a stored entity), 2.7 `SignalGroup` / `Phase` / `SignalTiming`, 3.1 `VehicleState` /
`LaneState` / `SignalState` / `TrueState`, 3.2 `RunCounters`, 4.1 `Detection` / `Observation`,
4.2 `LaneEstimate` / `EstimatedState`, 5 `PhaseRequest` / `RequestOutcome` / `ActionResult`.

All frozen and slotted. All ID types as `NewType(..., int)`.

Implement all sixteen invariants of `05_DOMAIN_MODEL.md` §8 as a `validate_network()`
function raising a typed error naming the violated invariant and the offending entities.

## Scope
1. `traffic_lab/domain/` with the types above, split into modules by §: `network`, `state`,
   `observation`, `action`.
2. `validate_network()` covering invariants 1–9 and 15–16.
3. `movements_of(junction)` computing the `Movement` view from lane connections.
4. Tests: one per invariant, each asserting that a deliberately malformed network is
   rejected with the right error.

## Non-goals
1. Do NOT add any field not in `05_DOMAIN_MODEL.md`. The inclusion test (§1.1) is binding —
   if you believe a field is missing, **escalate**, do not add it.
2. Do NOT store `Movement`. It is a view. `D-011`.
3. Do NOT add base classes, `ABC`s, or a common `Entity` parent. `D-031`.
4. Do NOT import anything from other `traffic_lab` packages. `domain/` depends on nothing.
5. Do NOT add serialisation logic beyond what Pydantic/dataclasses give for free.

## Acceptance criteria
- [ ] Every type in `05_DOMAIN_MODEL.md` §§2–5 exists with exactly its fields and units.
- [ ] Sixteen invariant tests, each named for its invariant number.
- [ ] A property-based test (`hypothesis`): a phase containing a `CONFLICTING` pair is always
      rejected, for randomly generated conflict matrices.
- [ ] `mypy --strict traffic_lab/domain/` clean.
- [ ] An import test asserts `traffic_lab.domain` imports nothing from `traffic_lab.*`.

## Escalate if
1. A type in `05_DOMAIN_MODEL.md` cannot be expressed as specified.
2. Two invariants in §8 contradict each other.
3. You believe a field is missing. Name its consumer and escalate.
