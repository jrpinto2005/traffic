Three rules from §7 that are easy to get wrong and expensive to get wrong:

1. **The replication unit is the run, not the vehicle** (§6.3). One run contributes **one
   number** per metric. Treating per-vehicle samples as independent inflates the effective
   sample size by three orders of magnitude and produces intervals so tight that every
   difference looks significant. This is the easiest way to produce a confidently wrong result
   in this project.
2. **BCa bootstrap, 10,000 resamples**, over paired differences — delay distributions are
   skewed and the bootstrap costs nothing on 30–100 numbers.
3. **Relative effect with its interval**, not absolute seconds, since the whole point is
   comparing across demand levels.

## Scope
1. The three functions above.
2. `viz/style.py`: one project style module fixing fonts, colours, figure sizes, and the house
   convention for showing uncertainty. Consistency across figures reads as rigour far more
   than any individual chart does.
3. The M1 headline figure.
4. A results table: per arm and demand level, the metric, its CI, n, and the trip completion
   rate.
5. Validity reporting: invalid runs by cause, printed even when zero.

## Non-goals
1. Do NOT use plotly, bokeh, or seaborn. Matplotlib plus the style module. `D-004`.
2. Do NOT make figures interactive. Static, versionable output.
3. Do NOT compute statistics on per-vehicle rows. See rule 1.
4. Do NOT drop invalid runs silently. Report them.
5. Do NOT invent additional statistical tests beyond §7.

## Acceptance criteria
- [ ] The BCa implementation reproduces a known reference interval on a textbook dataset.
- [ ] `required_replications` matches a hand-computed value.
- [ ] Holm–Bonferroni matches a hand-worked example.
- [ ] A test asserts the analysis path never aggregates per-vehicle rows into an interval.
- [ ] The headline figure regenerates from a committed config on a clean checkout.
- [ ] Every reported number carries metric name, unit, n, and CI.

## Escalate if
1. Fewer than 30 valid seeds survive the validity gate for any arm.
2. The pilot estimate of `σ_d` implies a replication count that is impractical — that is a
   real finding about the experiment's power, and it belongs in the results document.
