# T1.13 — Profiling harness and performance baseline

**Archetype:** Builder · **Depends on:** T1.4 · **Implements:** `D-031`

## Context
Per `D-031`, code-level efficiency is adopted as **infrastructure rather than attitude**.
"Write fast code" is advice everyone already agrees with and that changes nothing. What
changes something is a committed tool that says where the time actually went.

Small ticket. Its value is entirely in existing from M1 rather than being built when something
is already too slow.

## Contract

```bash
traffic-lab profile <config> [--top N]
```

Runs a standard scenario under a profiler and emits a hot-path report: cumulative time by
function, wall-clock per simulated hour, peak memory. Output is both human-readable and a
machine-readable record appended to `research/performance_baseline.jsonl`.

## Scope
1. The `profile` subcommand wrapping cProfile.
2. Wall-clock-per-simulated-hour measurement.
3. Baseline record appended per invocation, tagged with code version.
4. A regression check: compare against the last recorded baseline and warn on material
   degradation. **Warn, do not fail** — a genuinely more expensive controller is a legitimate
   reason to be slower, and the check exists to make the change visible rather than to block it.
5. A short `research/M1_hotpaths.md` reporting where the time went at M1.

## Non-goals
1. Do NOT optimize anything found. Reporting is the deliverable. `D-031`.
2. Do NOT add continuous benchmarking or CI integration.
3. Do NOT profile inside normal runs. Opt-in subcommand only.
4. Do NOT add a second profiler (py-spy, scalene) unless cProfile proves inadequate — and
   then escalate rather than adding it.

## Acceptance criteria
- [ ] `traffic-lab profile configs/smoke.yaml` produces a report and appends a baseline record.
- [ ] Wall-clock per simulated hour is within range of T0.3's measurement; explain if not.
- [ ] The regression check warns on an artificially slowed build and stays silent otherwise.
- [ ] `research/M1_hotpaths.md` exists and names the top consumers.

## Escalate if
1. The measured hot paths differ substantially from those `D-031` anticipates — that is a
   finding worth registering, since `D-031`'s remedy list was written from expectation.
