# T1.15 — Stop-line detection zone

**Archetype:** Builder · **Depends on:** T1.9, T1.14 · **Implements:** `D-036`, `D-033`

## Context
Added 2026-10-07 from T1.10's pre-issue review. `D-013`'s actuated controller must extend green
on gaps, and `EstimatedState` carried nothing a gap could be measured from. `D-036` adds the
smallest thing that makes it possible: how far each detected vehicle is from the stop line, and
how many vehicles are in each lane's detection zone. T1.10's actuated controller consumes it.

## Contract
```python
# traffic_lab/domain/observation.py
class Detection:          # gains, after stationary_s:
    distance_to_stop_m: float | None   # front to the end of its lane; None if unknown

class LaneEstimate:       # gains, after vehicle_count:
    zone_count: float     # vehicles with 0 <= distance_to_stop_m <= zone length

# traffic_lab/sensing/oracle.py
class OracleSensor:
    def __init__(self, sensor: SensorId, network: Network) -> None: ...
    # distance_to_stop_m = lane.length_m - vehicle.position_on_lane_m, lane from `network`

# traffic_lab/estimation/identity.py
class IdentityEstimator:
    def __init__(self, network: Network, *, zone_s: float = 2.0) -> None: ...
    # zone length of a lane = zone_s * lane.speed_limit_mps (D-036)
```
`zone_s = 2.0` is `D-036`'s value, not an invented default. Every lane gets a zone, internal lanes
included; consumers decide which lanes they care about. A detection with
`distance_to_stop_m is None` is incomplete and raises, like a missing `lane` today.

## Scope
1. The two fields, the oracle's distance, the estimator's zone count, and every existing
   constructor call and test updated.
2. Extend `tests/estimation/test_identity_exactness.py`: at every step and at Δt = 5 s, each
   `zone_count` equals a count made directly from `TrueState` and the `Network`.

## Non-goals
1. Do NOT implement a controller. That is T1.10.
2. Do NOT add a zone per detector, an occupancy measure, or a passage-event stream. One count.
3. Do NOT modify `tests/generated_scenario.py` or `tests/backend/conftest.py` — T1.8 is
   running concurrently and may; use them as they are.

## Acceptance criteria
- [ ] Oracle distances equal `length_m - position_on_lane_m` for every vehicle, on a real run.
- [ ] `zone_count` exact against `TrueState` on the real simulator, every step and at Δt = 5 s,
      with a non-vacuity check (zones occupied at some sampled steps, empty at others).
- [ ] Boundary: a vehicle exactly at the zone length counts; one just beyond does not.
- [ ] All four checks pass; the import boundaries from T1.9 still hold.

## Escalate if
1. `Network` lane IDs and `TrueState` lane IDs disagree for any lane (T1.3's A2 says they cannot).
