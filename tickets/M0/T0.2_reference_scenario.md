# T0.2 — Reference scenario and adapter smoke test

**Archetype:** Spike
**Milestone:** M0
**Depends on:** T0.0
**Implements decisions:** informs `D-003`, `D-023`
**Blocks:** T0.3, T0.4, T0.5

## Context
Every other M0 spike measures something about SUMO, and all of them need the same small
network to measure it on. This ticket produces that network and proves we can read state
from it and write signals to it.

## Questions
1. What does a hand-built four-way signalized intersection look like as SUMO XML
   (`.nod.xml`, `.edg.xml`, `.con.xml`, `.tll.xml`, `netconvert` invocation)?
2. Which state fields can we read per step, and what exactly does each mean? Confirm at
   minimum: `timeLoss`, `waitingTime`, `getLastStepHaltingNumber`, lane occupancy, vehicle
   position, speed, and type.
3. How is a signal program set and overridden from Python mid-run?
4. **How does SUMO represent junction conflicts** (the `<request>` / response matrix), and
   can it seed the three-valued conflict matrix `D-023` specifies?

## Method
Build the network by hand, not with `netgenerate` — the point is to understand the format
we will later generate programmatically.

Scenario: four approaches, two lanes each, 200 m, 50 km/h, protected turns only, two phases
(NS, EW), constant demand from all four approaches.

## Deliverable
- `spikes/M0_reference/` containing the network files and a script that runs it headless and
  prints per-step state.
- `research/M0_reference_scenario.md`: the network format explained, a **table of every
  state field with its exact meaning and unit**, how to set a signal program, and what
  SUMO's conflict representation gives us toward `D-023`.

## Non-goals
1. Do NOT build a network generator. That is T1.3.
2. Do NOT build an adapter abstraction. That is T1.4. A flat script is correct here.
3. Do NOT add demand beyond constant flows. Attrition and turn ratios are T0.5.
4. Do NOT implement any controller.

## Escalate if
1. SUMO's conflict representation cannot distinguish permitted from conflicting movements —
   that would force a change to `D-023`.
2. A state field we assumed exists does not, or means something different from what
   `05_DOMAIN_MODEL.md` §3.1 assumes.

## Definition of Done
Per `08_AGENT_HANDOFF_PROTOCOL.md` §5, Spike section. The scenario must be reusable by
T0.3, T0.4 and T0.5 without modification.
