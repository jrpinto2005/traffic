# T0.0 — Environment setup

**Archetype:** Builder
**Milestone:** M0
**Depends on:** nothing
**Implements decisions:** `D-004`
**Blocks:** every other ticket in the project

## Context
Nothing can run yet. Python 3.12.1 is present; SUMO, `uv`, and the project virtualenv are
not. This ticket makes the toolchain real and pins the versions that go into every run
manifest.

## Scope
1. Install SUMO (macOS: `brew install --cask sumo-gui` or `brew install sumo`; confirm which
   provides `sumo`, `sumo-gui`, `netgenerate`, `netconvert`, `jtrrouter`, `duarouter`).
2. Set and persist `SUMO_HOME`, and confirm `$SUMO_HOME/tools` is importable from Python
   (`import traci`, `import libsumo`, `import sumolib`).
3. Install `uv`.
4. Create the project virtualenv with Python 3.12 and a `pyproject.toml` declaring:
   `numpy`, `polars`, `pyarrow`, `duckdb`, `pydantic>=2`, `matplotlib`, `pytest`,
   `pytest-cov`, `hypothesis`, `ruff`, `mypy`.
5. Record exact versions of Python, SUMO, and every dependency in
   `research/M0_environment.md`.

## Non-goals
1. Do NOT create the `traffic_lab/` package. That is T1.1.
2. Do NOT install anything not listed above. No RL libraries, no notebook tooling.
3. Do NOT configure CI.

## Acceptance criteria
- [ ] `sumo --version`, `netgenerate --help`, `jtrrouter --help` all succeed.
- [ ] `python -c "import traci, libsumo, sumolib; print('ok')"` succeeds inside the venv.
      **If `libsumo` is unavailable in this SUMO build, escalate — it is not optional
      (`D-002`).**
- [ ] `uv sync` reproduces the environment from a clean checkout.
- [ ] `research/M0_environment.md` lists every pinned version.

## Escalate if
1. `libsumo` is not importable from the installed SUMO build.
2. The available SUMO version is below 1.19 (older releases differ in state-saving and
   subscription behaviour that `D-032` and `D-031` depend on).
3. Installation requires changes outside this project directory beyond SUMO itself and `uv`.
